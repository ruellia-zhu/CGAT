# 1.0.2：修复比对结果与 WGDI 基因 ID 不对应

程序位置：`E:\ComparativeGenomicsAnalysisTool\dist\比较基因组分析\比较基因组分析.exe`。

重新打开程序，打开已有分析项目，在“点阵图”步骤点击“运行本步”即可。无需重新预处理或重跑 DIAMOND。

## 原因与修复

跨物种比对使用 B 的蛋白查询 A 的库，原始结果前两列因此是 B、A；此前生成的 WGDI 配置要求 A、B，导致匹配记录为空。该方向问题同时涉及 DIAMOND 和 BLASTP。

现在运行 WGDI 前会核对前两列与两个预处理 GFF 的实际对应关系。对于反向结果，生成 `work/<物种A>-<物种B>.wgdi.blastp.txt`，同步交换基因 ID 和查询/目标坐标；原始比对表保留。点阵图、共线性和块汇总统一引用转换后的文件；后续步骤重写配置时也保持一致。正向结果和自比较保持原方向。

真正的 ID 不匹配、比对表不足 12 列、过滤后无可用命中会给出具体提示。WGDI 提前停止或没有生成预期文件时，不再仅凭退出码 0 标记成功。

## 验证

- 16 项新增回归测试通过；11 项预处理测试、18 项数据读取测试通过。
- 少量合成基因组经过自动预处理、真实 DIAMOND / BLASTP 比对、真实 WGDI 点阵图，两种引擎均通过。
- 使用实际项目 `analysis-20261103-000628` 的副本复现：414,796 行全部匹配 B→A，A→B 匹配为零；原配置复现同一报错。
- 修复后，实际数据的 WGDI 点阵图、共线性识别和块汇总均成功，得到 1,418 个共线块。验证未计算 Ks。
- 实际项目与原始比对表未改动。验证副本、日志、构建文件和旧版程序备份集中位于 `build/bugfix_20261103/`。

可移植测试入口：`tests/test_blast_direction.py`。
