# 比较基因组分析 1.0.3

发布日期：2026-11-03。

## 使用变化

- 程序启动默认显示 **WGDI 全流程分析**。
- 预处理页面新增“打开已有项目”和“新建项目”。选择包含 `project.json` 的项目目录可恢复向导设置及完成状态。
- 修改输入或参数后，对应结果和下游结果会失效；请从提示的步骤重跑，也可连续运行。1.0.2 及以前没有完整验证记录的项目会保守地要求重新验证、运行。
- 旧结果不会被直接删除。重跑覆盖输出前，会把它们移入项目 `history/`；分块比对、Ks 的有效缓存分别保存在 `work/chunks/`、`work/ks_cache/`。
- 物种内部文件前缀与显示名称分离，新项目使用不同的 A/B 文件键，改图上名称不会改变已有文件路径。
- 全流程 Circos 页的 PDF、SVG、PNG 选择实际生效，选择会保存进项目。
- 本机线程数和 WGDI process 限制为 1–8。MAFFT 启动自检不通过时禁用选项；默认 MUSCLE 可正常完成 Ks。

## Ks 结果的成功判据

计算仍由 WGDI、MUSCLE/MAFFT、pal2nal 和 PAML 完成，应用提供输入和工具适配及结果校验。

所有有效基因对均成功时正常完成；部分基因对无法估计时只发布有效结果，并在日志和步骤详情中保存期望数、有效数、失败数和剩余数。无任何有效数值时标记失败。重新运行 Ks 可从同一输入的有效缓存继续，并重试未成功的基因对。更换序列、共线性输入或比对算法时使用不同缓存，不能混用旧结果。
